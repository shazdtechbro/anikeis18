# Her Majesty, Anike

A personal birthday website with photo memories, a video, and a downloadable love letter. Built with HTML, CSS, and JavaScript. Images, video, and fonts are stored locally.

## Local development

From the repository root, run:

```sh
python3 -m http.server 8000
```

Open the local server in your browser. No package installation or build is required.

## Deploy to Vercel

Import `shazdtechbro/anikeis18` into Vercel and select the `main` branch. Use the repository root, the Other framework preset, no build command, and `.` as the output directory. The included `vercel.json` provides the static deployment settings. No environment variables are required.

The deployed site includes personal photos and messages. Configure deployment protection in Vercel if access should be limited.
